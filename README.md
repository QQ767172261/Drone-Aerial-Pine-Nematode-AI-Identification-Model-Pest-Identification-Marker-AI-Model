## 应用价值
1. **森林病虫害快速普查**：针对大面积林区航拍正射影像，自动识别标记松材线虫病受害松树斑块，快速圈定病害范围，替代人工目视判读，极大缩短外业+内业调查周期。
2. **林业动态监测**：持续监测林区病害扩散范围，追踪松材线虫病发展趋势，为病害预警、治理方案制定提供数据支撑。
3. **航飞数据自动化后处理**：对接无人机航测产出的GeoTIF拼图，直接输出带空间位置的病害标记成果，成果自带地理坐标，可直接导入GIS平台。
4. **降低项目人力成本**：减少林业内业判图人员重复标注工作，提升航飞项目交付效率，适合大面积林区批量影像处理。
5. **辅助外业核查**：模型输出病害斑块坐标，指导现场人员定点核查，精准定位病害区域，减少野外无效巡护路程。
